# frontend/public/images/children/generated/README.md

This folder holds review-ready, AI-assisted child cutouts derived from programme photographs with guardian publication permission.
Use the transparent WebP files in the website; local PNG generation and alpha-review masters are intentionally ignored.

These images are expressive promotional derivatives, not documentary photographs of Gurukulam classes or campus activities. Confirm guardian approval for identity-preserving AI derivatives before public release, and compare each face with its named source photograph before use.

Every generated child uses the same pale sandalwood ISKCON-style Vaishnava tilak: two fine U-shaped forehead lines continuing into the traditional leaf mark on the upper nose. Performance-specific face decoration may remain around that shared tilak.
